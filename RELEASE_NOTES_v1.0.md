# 231Dictionary v1.0 — Release notes

**Author:** Lee Sang Il  
**Platform:** Windows 10/11 (x64)  
**Version:** 1.0.0.0

- English-language tray menu, API key setup, installer messages and program information.
- Gemini-powered Korean ↔ English sentence translation, with the selected text's line breaks preserved and key vocabulary displayed underneath.
- Optional exclusion of ordinary browser pages while permitting detectable in-browser PDF documents.
- KakaoTalk is excluded from translation regardless of the browser-exclusion preference.
- Retains the existing English word-hover feature from v3.3.1; it may not work reliably in all PowerPoint or PDF environments.
- API key is provided by the user, not bundled with the application.

**Testing:** unit tests and cross-compilation on Linux were carried out in prior development. A native Windows end-to-end validation is still required.
