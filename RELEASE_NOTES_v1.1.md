# 231Dictionary v1.1

Created by **Lee Sang Il**. Windows 10/11 (64-bit).

## About 231Dictionary

231Dictionary is a Windows translation utility that helps users understand Korean and English text in supported documents, including PowerPoint and selectable-text PDF files. It uses Google Gemini for online translations and requires a personal Gemini API key.

## Features

- Translate selected English sentences into Korean, and selected Korean sentences into English.
- Show explanations of important words and expressions below sentence translations.
- Preserve line breaks from the source where the application exposes selectable text.
- Display English word meanings in a tooltip where text recognition is supported and the feature is enabled.
- Exclude KakaoTalk from translation. Optionally exclude regular browser web pages while allowing supported browser PDFs.
- Use an English-language interface and encrypted per-user storage for the Gemini API key.

## Important

The executable is not digitally code-signed. Windows Defender SmartScreen may display a warning for a new or unsigned application, including when extracted from ZIP. Only install software allowed by your organization's policies.

Selected text can be transmitted to Google Gemini. Avoid confidential or personal information that must not leave your organization. Google Gemini API credentials are not included in the installer.
