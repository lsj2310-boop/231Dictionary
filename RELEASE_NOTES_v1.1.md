# 231Dictionary v1.1 — Configurable Global Toggle Shortcut

Created by **Lee Sang Il**. Windows 10/11 (64-bit).

## What's new

- New **Set / Change Toggle Shortcut...** tray menu item.
- Configure a global shortcut such as **Ctrl+Alt+T** or **Ctrl+Shift+F5** to toggle the checkmark for **Enable / Disable Word Tooltips**.
- The shortcut setting persists after restarting the application.
- Occupied or invalid shortcut combinations are rejected without losing the previous one.
- The **Remove Toggle Shortcut** menu item unregisters the shortcut.
- Repeated key presses are suppressed while a shortcut is held.

## Unchanged from v1.0

- Gemini English-to-Korean and Korean-to-English translation, with key terms explained.
- Translation from selected text, line-break preservation, and word tooltips when enabled.
- Browser web page exclusion with PDF exception, and KakaoTalk exclusion.
- English interface and encrypted per-user Gemini API key.
