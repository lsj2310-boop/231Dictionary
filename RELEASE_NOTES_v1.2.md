# 231Dictionary v1.2

**Created by Lee Sang Il** · Windows 10/11 (64-bit)

## What's new

- **PDF Craft compatibility:** Enhanced recognition of selected text in PDF Craft, with a controlled copy-text fallback for supported viewers.
- **Copy translated English:** Right-click a completed Korean-to-English translation popup to copy **only the English translation**, excluding key words and expressions.
- **Move the translation popup:** Left-click and drag the popup to change its position. The popup stays visible while the mouse remains over it.

## Continued features

- Bidirectional English ↔ Korean sentence translation using Google Gemini.
- Important word and expression explanations beneath the translation, with source line breaks preserved where available.
- Supported browser PDF exception, KakaoTalk exclusion, and secure per-user API key storage.

## Downloads

- `231Dictionary_Installer_v1.2.exe` — Windows 64-bit installer.
- `231Dictionary_v1.2_Installer.zip` — same EXE with English guide and notices.

## Important

Not digitally code-signed: Windows SmartScreen warnings may still appear after downloading either EXE or ZIP. Install only according to your organization's security policies. Text selected for translation may be transmitted to Google Gemini. Do not submit confidential or private data without authorization. Your own Gemini API key is required and is not bundled with the application.

PDF Craft support and popup mouse behavior were implemented and automatically tested, but not verified on the user's Windows PC.
