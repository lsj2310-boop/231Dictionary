# 231Dictionary v1.3

Created by **Lee Sang Il**. Windows 10/11 (64-bit).

## Updated

- Single left-click on the notification-area icon toggles translation ON/OFF.
- Colored (teal) icon indicates ON; gray icon indicates OFF.
- Right-click menu checkbox, existing optional shortcut, and tray icon share the same state.
- The ON/OFF setting survives an application restart.
- Duplicate toggles from double-click events are suppressed.
- Switching OFF cancels pending word or sentence translation results and hides the current popup.

## Unchanged

- Gemini English-to-Korean and Korean-to-English translation with key terms.
- Source line-break preservation, popup text copy/move, and PDF Craft selection support.
- Browser PDF exception, KakaoTalk exclusion, and encrypted per-user Gemini API key.

## Install

Download `231Dictionary_Installer_v1.3.exe` or `231Dictionary_v1.3_Installer.zip`, close the old tray instance, and run the installer. The EXE is not code-signed, so Windows security warnings may appear; follow your organization's policies.
